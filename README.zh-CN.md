# Editor

[English](./README.md) | 简体中文

在思源里打开、编辑笔记链接到的文本文件。编辑器用你的思源代码字体与你选定的语法配色。

## 它做什么

思源把指向 `assets/` 下文件的链接当作普通超链接渲染，点击后交给系统默认程序——可能是个文本编辑器，也可能什么都没有。本插件把它改到思源里打开：桌面端是一个带语法高亮、行号、搜索、撤销与重做的独立页签（也可以在设置里改成浮层），移动端是一个铺满屏幕的弹窗。

四种入口：

- 点击资源文本文件的链接（默认开启接管时）。
- 右键链接，在「插件」子菜单里选「使用 Editor 打开」。
- 关掉接管，只用菜单入口。
- 右键笔记文档，在「插件」子菜单里选「预览 .sy 文件」，只读查看该文档的 `.sy` 源文件（需先在设置里开启）。

只处理工作区 `assets/` 目录下的文件。指向工作区外绝对路径的链接（`file:///...`）不做处理。.sy 预览只处理工作区内的笔记文档。

## 环境要求

- 思源 3.8.3 及以上。
- 桌面端、Docker 部署后用桌面浏览器访问的网页版，以及移动端（手机 App 与手机浏览器）。思源的自定义页签 API 在移动端是空实现，所以移动端没有页签，同一个编辑器改用一个全屏弹窗承载；思源弹出的独立窗口里也没有页签栏，那里改用浮层承载。`plugin.json` 的后端与前端都声明为 `all`。
- 需要管理员角色。定位与写回资源用到 `/api/asset/resolveAssetPath`、`/api/asset/statAsset` 与 `/api/file/putFile`，思源把这几个接口限制给管理员。单人本地工作区一直是管理员。

## 安装

市集安装：**设置 - 集市 - 已下载 - 插件**，搜索 Editor。

手动安装：把 `package.zip` 解压到 `<工作空间>/data/plugins/editor-siyuan/`，再启用。

## 保存

不主动保存就不会写盘。用代码块右上角的保存按钮，或 `Ctrl+S`（macOS 上是 `Cmd+S`）。只要有未保存的改动，保存按钮就会一直可见。

写回一律用 UTF-8，并保留原文件的字节序标记与换行风格，所以打开再保存一个 CRLF 文件不会把每一行都改写一遍。

保存快捷键注册为插件命令，可在 **设置 - 快捷键 - 插件** 里改。

## 格式化与压缩

操作条最右侧的「更多」里有两项：**代码格式化**与**代码压缩**。都作用于整篇正文，改动只进撤销栈、不落盘，`Ctrl+Z` 一次就能退回；预览模式下两项置灰。

笔记里的代码块也有这两项，在代码块右上角的 **更多 - 插件** 子菜单里，改的是那一个代码块，同样只进撤销栈。按代码块自己的语言判断能不能做：本插件没实现的语言（Python、Go 之类）不出现这两项，只读文档里出现但置灰。可以在设置里关掉。

| 语言 | 格式化 | 压缩 |
| --- | --- | --- |
| JavaScript | 是 | 是 |
| JSON / JSONC | 是 | 是 |
| CSS | 是 | 是 |
| TypeScript / TSX、SCSS、LESS、HTML / XML / Vue、YAML、Markdown | 是 | — |

格式化用 [prettier](https://prettier.io/)。压缩 JavaScript 用 [uglify-js](https://github.com/mishoo/UglifyJS)，它会压缩并混淆局部变量名；压缩 CSS 用 [csso](https://github.com/css/csso)，只去注释与空白、不合并规则；压缩 JSON 直接走 `JSON.parse` + `JSON.stringify`，所以 JSONC 里的注释与尾随逗号会被去掉。缩进跟随思源的「代码块 Tab 空格数」。

TypeScript、JSX、SCSS、LESS、HTML、YAML、Markdown 没有可靠的浏览器内压缩实现，所以只提供格式化。

## 设置

**设置 - 集市 - 已下载 - 插件 - Editor - 设置**。

| 设置项 | 默认值 | 含义 |
| --- | --- | --- |
| 接管资源文本文件的点击 | 开 | 点击白名单内链接时是否用本编辑器打开，而不是交给系统默认程序 |
| 接管手势 | 单击 | 用哪个手势接管。其余手势保持思源原有行为，所以 Alt 或 Shift 单击仍然是「使用默认程序打开」，Ctrl 单击仍然是「打开文件位置」。移动端没有修饰键，这一项不显示，单击即接管 |
| 支持预览 .sy 文件 | 关 | 笔记文档的菜单里是否多一项，以只读页签查看该文档的 `.sy` 源文件 |
| 支持格式化与压缩代码块 | 开 | 笔记的代码块菜单里是否多出「代码格式化」与「代码压缩」两项 |
| 文件扩展名 | 常见文本与代码扩展名列表 | 哪些资源在这里打开，一行一个 |
| 大小上限（MB） | 5 | 超过该体积的文件不在此打开 |
| 关闭前确认 | 开 | 关闭有未保存改动的编辑器前先确认 |
| 暂存未保存内容 | 开 | 编辑器关闭时保留未保存的正文，下次打开同一文件时询问是否恢复 |
| 打开时的默认模式 | 编辑 | 新打开的文件先进入编辑还是只读预览，已打开的编辑器不受影响 |
| 桌面端形态 | 页签 | 新打开的文件做成页签还是浮层。浮层没有关闭按钮，按 `Esc` 或点浮层外的空白关闭，有未保存改动时先确认。思源弹出的独立窗口一律用浮层。移动端不显示这一项 |
| 行号 | 始终显示 | 代码左侧是否显示行号 |
| 换行 | 跟随思源设置 | 超出编辑器宽度的内容是否自动换行 |
| 连字 | 跟随思源设置 | 代码字体的连字是否生效，例如 `=>` 与 `!=` |
| 恢复位置 | 开 | 重新打开时回到上次的滚动位置与光标 |
| 调试模式 | 关 | 在浏览器控制台输出详细日志，供排查问题 |
| 已记住的内容 | — | 记住了多少条按文件的选择，以及一个清除按钮 |

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+S` / `Cmd+S` | 保存当前编辑器里的文件，可改键 |
| `Ctrl+F` / `Cmd+F` | 打开文件内搜索面板，已经打开时收起 |
| `Ctrl+W` / `Cmd+W` | 思源自己的「关闭页签」；有未保存改动时会先确认 |

其余操作都在操作条上，从左到右是：语言标签（点开是语法列表）、撤销、重做、换行开关，然后是查找、预览/编辑切换、保存与「更多」。

- 撤销与重做跟着编辑器自己的撤销栈走，`Ctrl+Z` / `Ctrl+Shift+Z` 没得可做时按钮就置灰；预览模式下这一对隐藏。
- 换行开关是状态按钮，开启时是主色。它只覆盖当前这个编辑器的「换行」设置，设置里的默认值不会被改写，下次打开仍按设置来。

查找图标点一下是开/关面板，右键点它只收起。移动端没有硬件键盘，保存用操作条上的保存按钮。

## 已知限制

这些都是插件 API 的边界，不是遗漏。

- **关闭整个思源窗口无法拦截。** 思源提供的页签生命周期回调是同步的、返回值被忽略，而它的确认框是异步的，所以在那里取消不了关闭。未保存的正文会被暂存，下次打开同一文件时询问是否恢复。
- **页签右键菜单里的关闭项与批量关闭同样拦不到**，能拦的只有页签的关闭按钮、关闭快捷键和双击页签。这几条路径没有可拦截的事件，同样由暂存兜底。
- **超过大小上限时无法把点击交回思源。** 接管必须同步发生，而文件体积要先问过内核才知道。所以超大文件会打开一个页签说明原因，并指引用链接右键菜单里的「使用默认程序打开」。
- **加密笔记本里的资源会被拒绝。** 内核会把它解析成临时目录下的明文副本，写回那份副本等于静默丢弃改动。
- **高亮复用思源自己的静态资源** `/stage/protyle/js/highlight.js/`——与它代码块用的是同一份脚本与样式表，所以 token 分类与配色完全一致。若未来版本挪走该路径，高亮会退化为纯文本。
- **每次改动都会整篇重算高亮**，前提是一次整篇不超过 8 ms。这笔预算能装下多少文本取决于内容：散文与 Markdown 最多，密集的代码最少。更大的文件会退回「停止输入后再补算」，颜色会稍晚一步落定。
- **行号用的是 CodeMirror 的行号列**，按思源的度量重新配色，并用编辑器背景铺底。思源自己的代码块是手工拼的行号列，两者不可能像素级一致。
- **格式化与压缩在主线程上算。** prettier 与 uglify-js 都在渲染进程里跑，几 MB 的文件会让界面停顿几秒；计算期间改动过正文的话，这次结果会被放弃。三者也都打进 `index.js`，插件包因此大了约 700 KB。
- **不检测外部改动。** 文件在页签打开期间被其它程序修改时不会察觉，重新打开页签才会看到。
- **浏览器里 `Ctrl+W` 关的是浏览器自己的标签页**，插件拦不住，只能靠 `beforeunload` 让浏览器弹出它那个通用确认框。Docker 与网页版请留意这一点：页签关闭确认与暂存在那条路径上都来不及跑。
- **浏览器里右键菜单的「粘贴」可能置灰。** 浏览器不允许脚本触发粘贴，只剩异步剪贴板可走，而它要求 HTTPS 或 localhost；不满足时菜单项置灰。正文里直接按 `Ctrl+V` 不受影响。
- **移动端没有页签。** 同一个编辑器挂在一个铺满屏幕的弹窗里，关闭只能点操作条最左边的 ×，有未保存改动时由它弹出确认。移动端的返回键与系统手势不经过插件，那条路径由暂存兜底。
- **移动端固定按单击接管。** 移动端没有修饰键，设置里的「接管手势」不显示；桌面端选过的 Alt 或 Ctrl 单击在移动端一律当作单击处理。
- **浮层没有关闭按钮。** 它的外壳就是思源自己的对话框：标题栏里是文件名，底色、阴影、拖动与调大小都是原生的，只去掉了右上角的 ×。关闭只有 `Esc` 与点击浮层外的空白两条路径，两条都会先问过未保存的改动。
- **思源弹出的独立窗口一律用浮层**，与「桌面端形态」的设置无关：那种窗口没有页签栏，插件页签落不下来。

## 开发

```
npm install
npm run dev        # 监听构建
npm run typecheck  # tsc --noEmit
npm run build      # vite build，然后在仓库根目录产出 package.zip
npm run icon       # 重新生成 assets/icon.png 与 assets/preview.png
npm run preview    # 仅按 assets/preview.html 重拍 assets/preview.png
```
